# Проверка поиска и сценариев

## Запуск

Из корня проекта, с установленными зависимостями:

```bash
python eval/run.py
```

Для другого пути отчёта:

```bash
python eval/run.py --output /tmp/ai-buddy-evaluation.json
```

Работает без сети, ключа LLM и запущенного сервера. Создаёт отдельную SQLite в памяти,
заполняет демо на фиксированную дату 2026-11-16 и добавляет фронтенд-подборку.
`DATABASE_URL` окружения не используется. Данные работающего приложения не читаются и не изменяются.

## Что проверяется

- `retrieval.json`: 42 вручную размеченных синтетических вопроса, ожидаемые `slug` материалов.
  Пользователь — `arina`; учитываются его роль и команда.
- `scenarios.json`: 10 описанных диалогов с явными критериями. Проверяются источники, запрет доступа,
  отсутствие отправки без подтверждения, подготовка заявки, самопроверка, помощь, неизвестная тема и отмена.
- `run.py`: запуск, вычисление метрик, запись полного отчёта. Ошибка контракта сценария даёт ненулевой код выхода;
  промах поиска фиксируется в метриках и отчёте, а не прерывает оценку.

Top-1 — ожидаемый материал на первом месте в выдаче `kb.search`.
Top-3 — ожидаемый материал среди первых трёх. Это оценка ранжирования, **до порога релевантности агента**:
наличие документа в Top-3 не гарантирует, что агент ответит по нему.
Проверки сценариев вызывают реальный обработчик агента в offline-режиме, а не оценивают ответы внешней LLM.

## Результат нового набора

| Проверка | Результат первого прогона |
|---|---|
| Поиск Top-1 | 38/42, 90,5% |
| Поиск Top-3 | 40/42, 95,2% |
| Контракты сценариев | 10/10 |

Полный отчёт — `results/latest.json`: каждый запрос, ожидаемая и фактическая выдача, оценки BM25,
ошибки сценариев, версия кода и SHA-256 обоих наборов. Отчёт перезаписывается при следующем запуске.

**Ограничения.** Это небольшой открытый набор, сформированный по текущей демонстрационной базе,
без независимой пользовательской выборки и отложенной проверки. Он нужен для воспроизводимой
проверки прототипа, не доказывает отсутствие выдумок LLM, безопасность всех сценариев или сокращение нагрузки.
Полные жизненные циклы согласований и передачи наставнику дополнительно проверяются в `tests/`.

Исходного набора для прежних цифр 34/42 и 8/10 нет. Этот набор создан заново, его результат нельзя
выдавать за восстановление прежнего эксперимента. Для слайдов используйте новые цифры вместе с
подписью «синтетический набор: 42 запроса / 10 проверок сценариев; offline». При изменении кода
или данных запускайте оценку повторно и обновляйте показатели по отчёту.
