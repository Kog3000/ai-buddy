# Сценарий 7. Инструменты наставника (по ответам организаторов)

### Requirement: Встречу назначает и стажёр, и наставник
- **WHEN** наставник на экране «Встречи» выбирает своего стажёра и время в календаре общих свободных окон
- **THEN** стажёр получает приглашение (уведомление и сообщение в чат), на странице «Наставник» — «Подтвердить» / «Не смогу»
- **AND** автор может отозвать неподтверждённое приглашение; подтверждает только приглашённый
- Назначать встречи можно только своим стажёрам (403 для чужих)

### Requirement: Часть задач чек-листа отмечает только наставник
- Задачи `MENTOR_CONFIRMED_TASKS` (локальный запуск, первый MR, разбор ревью, презентация, итоги 1:1) у стажёра
  с пунктирным квадратом; отметить их сам он не может (403)
- **WHEN** стажёр нажимает «Попросить подтвердить» или говорит боту «готово» по такой задаче
- **THEN** задача получает статус «ждёт подтверждения», наставник — уведомление и карточку в «Сводке по стажёрам»
- **WHEN** наставник отмечает задачу на карточке стажёра или в чате
- **THEN** задача закрыта с пометкой «подтвердил наставник», стажёр получает уведомление
- Автозакрытие по событиям сервисов работает для любых задач

### Requirement: База ответов AI-buddy
- Ответ наставника по галочке сохраняется в отдельную базу (не в общую базу знаний), используется агентом с весом ×0.9,
  в каталоге и поиске не показывается; наставник/руководитель команды может удалить ответ

### Requirement: Материалы от наставника
- Куратор ведёт подборки статей по направлениям (Frontend, Backend, Аналитик…) — экран «Подборки статей»
- Закреплённый наставник выдаёт стажёру подборку целиком или свою ссылку (например, Хабр) в категорию
- Стажёр видит «Материалы от наставника» в базе знаний и отмечает прочитанное; повторно одна ссылка не выдаётся

### Requirement: Итоговый отчёт и анкета
- Отчёт по стажёру: этапы, цели, изученные материалы, вопросы по темам, встречи 1:1, анкета стажёра
- Черновик письма-характеристики собирается из данных; наставник редактирует, сохраняет, копирует, печатает в PDF;
  руководитель и куратор читают
- Стажёр заполняет анкету (3 оценки 1–5 и 2 вопроса) в «Моём прогрессе»; задача «Пройти опрос о стажировке»
  закрывается автоматически; сводка — в «Метриках». Расчёт сэкономленного времени убран.
