# Поиск, самопроверка и помощь стажёру

## Requirement: Компактные учебные сценарии
- В чате стажёра доступны «Найди материал по теме», «Проверь мои знания», «Я застрял».
- Сценарии работают без ключа LLM и не выгружают целиком уроки или видеотеку в ответ.
- Явный новый запрос переключает сценарий, «Отмена» завершает текущий диалог.

### Scenario: Поиск материала
- WHEN тема не указана, THEN бот задаёт один вопрос о теме.
- WHEN тема указана, THEN возвращает до трёх доступных материалов с короткими аннотациями и ссылками.
- WHEN результатов нет, THEN сообщает об этом и предлагает уточнить тему.
- Материалы наставников/других команд не должны раскрываться стажёру.
- Тест: `test_material_search`, `test_learning_permissions_and_missing_topic`.

### Scenario: Самопроверка
- WHEN тема поддерживается подготовленным банком, THEN бот задаёт три вопроса по одному с вариантами ответа.
- После ответа показывает разбор и отдельную кнопку перехода к следующему вопросу.
- Итог содержит число верных ответов и ссылки на темы для повторения; не меняет чек-лист и прогресс чтения.
- Вопросы — редакционные вопросы AI-buddy, не задания авторов курса и не проверка видеорасшифровки.
- Неизвестная тема не подменяется другой: бот предлагает доступные темы.
- Невалидный ответ и повторное нажатие старой кнопки не продвигают проверку.
- Состояния проверки и результаты изолированы по пользователю.
- Тест: `test_quiz_journey`, `test_quiz_invalid_and_stale_actions`, `test_quiz_isolation_and_switch`.

### Scenario: Стажёр застрял
- WHEN «я застрял», «ничего не понял», «нифига не ясно», «не получается», «запутался», THEN уточнить контекст,
  если стажёр его ещё не сообщил; один вопрос за раз.
- WHEN тема известна, THEN дать небольшой следующий шаг и до трёх доступных источников, без выдуманного решения.
- Для рабочей задачи последовательно уточнить ожидаемое и фактическое поведение, затем уже предпринятые шаги.
- При повторной трудности предложить редактируемый черновик обращения наставнику с собранным контекстом.
- Отправка выполняется только существующим действием `escalate_confirm` после подтверждения стажёра.
- Тест: `test_stuck_variants`, `test_stuck_task_and_confirmed_escalation`.
